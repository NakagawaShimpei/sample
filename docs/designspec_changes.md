## 追加内容

### 1. コンポーネントローカルな状態（Section 3）

追加場所: `3. 状態管理 > DataContext` の直下

DataContext を経由せず、各ページコンポーネント内の `useState` で管理する状態。

| コンポーネント | state | 用途 |
|---------------|-------|------|
| `RoomListPage` | `filterCount: string` | 参加人数フィルターの入力値 |

---

### 2. UI実装方針への追記（Section 7）

追加場所: `7. UI実装方針` のテーブルに3行追加

| 項目 | 実装 |
|------|------|
| リアルタイムフィルタリング | コンポーネントローカルの `useState` で入力値を管理し、`Array.filter()` でクライアント側即時絞り込み（API 呼び出しなし） |
| インライン警告表示 | 入力値の変化に応じて算出した boolean を条件に `className="capacity-warning"` の `<p>` を表示・非表示 |
| ボタンの活性制御 | 警告条件が `true` のとき `disabled={true}` を付与し送信を防止 |

---

### 3. 参加人数フィルターの詳細（Section 7）

追加場所: `7. UI実装方針` の末尾

| 項目 | 内容 |
|------|------|
| 対象コンポーネント | `RoomListPage.tsx` |
| フィルター方式 | クライアント側リアルタイム（API 呼び出しなし） |
| 絞り込み条件 | `room.capacity >= Number(filterCount)` |
| 未入力時 | 全件表示（フィルターなし） |
| クリアボタン | `filterCount !== ''` のときのみ表示 |
| 0件時 | 「条件に合う会議室が見つかりません。」を表示 |

---

### 4. 定員超過警告の詳細（Section 7）

追加場所: `7. UI実装方針` の末尾

| 項目 | 内容 |
|------|------|
| 対象コンポーネント | `RoomReservePage.tsx` |
| 警告トリガー | `Number(attendeeCount) > room.capacity` |
| 表示内容 | `定員を超えています（定員: ◯名 / 入力: △名）` |
| 表示場所 | 参加人数入力欄の直下 |
| ボタン制御 | 警告表示中は予約ボタンを `disabled` にし送信を防止 |
| スタイル | `.capacity-warning`（赤枠・赤文字・薄赤背景） |
