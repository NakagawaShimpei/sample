# 機能仕様書 — 会議室・デバイス管理システム

## 1. システム概要

社内の会議室予約およびデバイス貸出を管理する Web アプリケーション。  
ユーザーはロール（一般ユーザー / 管理者）に応じた操作が可能。

---

## 2. ユーザーロール

| ロール | 識別子 | 説明 |
|--------|--------|------|
| 一般ユーザー | `user` | 会議室予約・デバイス貸出が可能 |
| 管理者 | `admin` | 全機能に加え、登録・削除・管理操作が可能 |

---

## 3. 画面一覧

| パス | 画面名 | アクセス権 |
|------|--------|-----------|
| `/login` | ログイン | 全員（未認証） |
| `/rooms` | 会議室一覧 | 全ロール |
| `/rooms/:roomId/reserve` | 会議室予約 | 全ロール |
| `/rooms/register` | 会議室登録 | 管理者のみ |
| `/reservations` | 予約一覧 | 全ロール |
| `/devices` | デバイス一覧 | 全ロール |
| `/devices/register` | デバイス登録 | 管理者のみ |
| `/loans` | 貸出一覧 | 管理者のみ |
| `/users` | ユーザー一覧 | 管理者のみ |
| `/users/register` | ユーザー登録 | 管理者のみ |

未認証でアクセスした場合は `/login` へリダイレクト。  
権限不足の場合はエラーメッセージを表示。

---

## 4. 機能詳細

### 4.1 認証

#### ログイン
- username / password を入力してログイン
- 認証成功時は `/rooms` へ遷移
- 認証失敗時はエラーメッセージを表示
- セッションはブラウザのタブを閉じると終了する

#### ログアウト
- ヘッダーのログアウトボタンから実行
- セッションを破棄し `/login` へ遷移

---

### 4.2 会議室管理

#### 会議室一覧（/rooms）

| 項目 | 内容 |
|------|------|
| 表示情報 | 会議室名・場所・定員・設備・本日の予約状況 |
| 全ロール | 予約ボタン（各会議室行に表示） |
| 管理者のみ | 削除ボタン（各会議室行に表示） |
| 削除時 | 確認ダイアログを表示。関連する予約もあわせて一括削除 |

#### 会議室予約（/rooms/:roomId/reserve）

入力項目:

| フィールド | 型 | 必須 | 説明 |
|-----------|---|------|------|
| 日付 | date | ✓ | 予約日 |
| 開始時刻 | time | ✓ | 予約開始時刻 |
| 終了時刻 | time | ✓ | 予約終了時刻 |
| 参加人数 | number | ✓ | 参加予定人数 |
| 会議名 | text | ✓ | 会議の名称 |
| 予約者名 | text | ✓ | 予約者の表示名（自動入力） |
| 参加者 | text | ✓ | 参加者名（カンマ区切り） |

バリデーション:
- 終了時刻は開始時刻より後であること
- 参加人数は会議室の定員以下であること
- 過去の日付は予約不可
- 同じ会議室・日時で重複予約不可

#### 会議室登録（/rooms/register）— 管理者のみ

| フィールド | 型 | 必須 |
|-----------|---|------|
| 会議室名 | text | ✓ |
| 場所 | text | ✓ |
| 定員 | number | ✓ |
| 設備 | text | ✓ |

---

### 4.3 予約管理

#### 予約一覧（/reservations）

| ロール | 表示範囲 | 操作 |
|--------|---------|------|
| 一般ユーザー | 自分の予約のみ | キャンセル |
| 管理者 | 全ユーザーの予約 | キャンセル |

- キャンセル時は確認ダイアログを表示
- キャンセル済み予約もステータス表示で一覧に残る

---

### 4.4 デバイス管理

#### デバイス一覧（/devices）

表示情報: デバイス名・種別・場所・管理番号・ステータス

デバイスステータス:

| ステータス | 表示 | 操作 |
|-----------|------|------|
| `available`（利用可能） | 全ロール | 貸出ボタン表示 |
| `inUse`（使用中） | 全ロール | — |
| `inUse`（自分が借用中） | 全ロール | 返却ボタン表示 |
| `inUse`（他者が借用中） | 管理者のみ | 強制返却ボタン表示 |
| `maintenance`（メンテナンス中） | 全ロール | — |

- 貸出・返却・強制返却はすべて確認ダイアログを表示
- 管理者はすべてのデバイスを削除可能（確認ダイアログあり、貸出中の場合は貸出レコードも削除）

#### デバイス登録（/devices/register）— 管理者のみ

| フィールド | 型 | 必須 |
|-----------|---|------|
| デバイス名 | text | ✓ |
| 場所 | text | ✓ |
| 管理番号 | text | ✓ |
| 種別 | select | ✓ |

種別の選択肢: `ノートPC` / `プロジェクター` / `Web会議機器` / `モニター` / `その他`

---

### 4.5 貸出管理

#### 貸出一覧（/loans）— 管理者のみ

- 現在貸出中のデバイス一覧を表示
- 表示情報: デバイス名・種別・場所・管理番号・借用者・貸出日時

---

### 4.6 ユーザー管理

#### ユーザー一覧（/users）— 管理者のみ

- 登録済みユーザーの一覧を表示
- 表示情報: ユーザー名・表示名・ロール
- 削除可能な対象: `user` ロールのユーザーのみ
- 削除不可: 管理者アカウント・自分自身

#### ユーザー登録（/users/register）— 管理者のみ

| フィールド | 型 | 必須 | 備考 |
|-----------|---|------|------|
| ユーザー名 | text | ✓ | ログインID |
| パスワード | password | ✓ | — |
| 表示名 | text | ✓ | 画面上の表示名 |
| ロール | — | — | 常に `user` で作成 |

---

## 5. 扱うデータ

### 会議室

| 項目 | 説明 |
|------|------|
| 会議室名 | 会議室の名称 |
| 場所 | フロアや建物 |
| 定員 | 最大収容人数 |
| 設備 | プロジェクターなど（複数可） |

### 予約

| 項目 | 説明 |
|------|------|
| 対象会議室 | 予約する会議室 |
| 予約日 | 利用日 |
| 開始・終了時刻 | 利用時間帯 |
| 参加人数 | 予定参加者数 |
| 会議名 | 会議の名称 |
| 予約者 | 予約したユーザー |
| 参加者 | 参加予定者（複数可） |

### デバイス

| 項目 | 説明 |
|------|------|
| デバイス名 | 機器の名称 |
| 種別 | ノートPC / プロジェクター / Web会議機器 / モニター / その他 |
| 場所 | 保管場所 |
| 管理番号 | 社内管理用の番号 |
| ステータス | 利用可能 / 使用中 / メンテナンス中 |

### 貸出

| 項目 | 説明 |
|------|------|
| 対象デバイス | 貸出中の機器 |
| 借用者 | 貸出中のユーザー |
| 貸出日時 | 貸出開始日時 |

### ユーザー

| 項目 | 説明 |
|------|------|
| ユーザー名 | ログインID |
| パスワード | 認証用パスワード |
| 表示名 | 画面上の氏名 |
| ロール | `user`（一般）または `admin`（管理者） |

---

## 6. 共通仕様

- 削除・キャンセル・貸出・返却の操作前には確認を求める
- バリデーションエラーや操作失敗時は通知を表示
- ページ上部でローディング中・エラー状態を表示
